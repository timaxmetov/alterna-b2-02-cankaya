# alterna-b2-02-cankaya

Alterna · B2 · Анкара · день 2: **Прибытие: первые часы в Чанкае** (Varış: Çankaya'da ilk saatler).

Интерактивный урок по дневной теме дорожной карты Alterna (`d.b2.02`).

- `d.b2.02/` — сам гайд в формате платформы (как `d.b1.NN` в alterna-guides). Для переноса в общую архитектуру копируется эта папка целиком, рядом с остальными `d.*`.
- `kit/v1/` — копия общего движка kit, нужна только чтобы сайт работал отдельно. При переносе не копируется: на платформе он уже есть.
- `index.html` — переход на `d.b2.02/`.

Собрано из `alterna-ankara-b2/src/days/d.b2.02.json` скриптом `tools/build.mjs`.
